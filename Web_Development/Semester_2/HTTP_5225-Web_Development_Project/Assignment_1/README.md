# MTG Card Display

This project fetches random Magic: The Gathering (MTG) card data from a MySQL database and displays it in a responsive table. Each card's details (name, release date, mana cost, etc.) are shown, and its image is dynamically loaded from the Scryfall API using AJAX. 

### Key Features:
- Fetches 50 random MTG cards from the database.
- Displays card details in a table format.
- Loads images dynamically using AJAX.

### Setup:
1. Set up a MySQL database with a table containing MTG card data.
2. Include the provided PHP code to fetch and display the card data.
3. Use jQuery for AJAX requests to load the card images from the Scryfall API.
